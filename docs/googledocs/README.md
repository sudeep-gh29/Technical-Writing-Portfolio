
# Module 5: Google Docs – Collaborative Writing

## 1. Introduction

Google Docs is a cloud-based word-processing application
that allows users to create, edit, format, and share
documents online.

It supports real-time collaboration, making it useful
for academic work, reports, and professional writing.

## 2. Objectives

- Understand the main features of Google Docs.
- Create and format professional documents.
- Use heading styles and document organisation.
- Collaborate through comments and suggestions.
- Generate and share PDF documents.

## 3. Important Features

### 3.1 Document Formatting

Google Docs provides formatting options such as:

- Font type, size, and colour.
- Bold, italic, and underline.
- Paragraph alignment and spacing.
- Bulleted and numbered lists.

### 3.2 Heading Styles

Heading styles help organise documents into
a clear hierarchy.

- Heading 1: Main sections.
- Heading 2: Subsections.
- Heading 3: Smaller sections.

### 3.3 Table of Contents

A table of contents can be inserted using
the document's heading styles.

It provides an organised overview and allows
readers to navigate between sections.

### 3.4 Collaboration Tools

Google Docs supports collaborative writing through:

- Real-time editing by multiple users.
- Comments for feedback and discussion.
- Suggesting mode for proposed changes.
- Version history to review earlier document versions.
- Sharing permissions for controlling access.

## 4. Creating a Document

The typical workflow for preparing a document is:

1. Open Google Docs.
2. Create a blank document.
3. Add a suitable title and headings.
4. Enter and format the content.
5. Insert tables, images, and a table of contents.
6. Review the document for errors.
7. Share the document for collaboration.

## 5. Exporting Documents

Google Docs supports downloading documents
in multiple formats.

To export a document as a PDF:

1. Open the document.
2. Select File.
3. Choose Download.
4. Select PDF Document (.pdf).

## 6. Advantages of Google Docs

- Accessible through a web browser.
- Automatic cloud saving.
- Real-time collaboration.
- Easy document sharing.
- Version history and review features.
- Convenient PDF export.

## 7. Conclusion

Google Docs provides an accessible platform
for collaborative technical writing. Its
formatting, review, sharing, and export features
support the creation of organised professional
documents.

It is particularly useful for academic
assignments and collaborative projects.
